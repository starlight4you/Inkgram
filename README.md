# Inkgram

> 为墨水屏而生的 Telegram 客户端。

Inkgram 基于 Telegram X 定制，为搭载 Android 的墨水屏设备带来更安静、清晰、专注的聊天与阅读体验。

## 为阅读留白

墨水屏不需要追逐流光溢彩。Inkgram 采用克制的纯黑白视觉风格，减少不必要的动态变化，让聊天、频道与长文阅读回到内容本身。

无论是在通勤途中浏览频道，还是在安静的夜晚处理消息，界面都以清晰、稳定和低干扰为目标。

## 墨水屏体验

- 黑白分明的视觉风格，文字与信息层次一目了然。
- 更克制的页面变化，减少频繁刷新带来的干扰。
- 适合长时间阅读消息、频道文章和文件内容。
- 翻阅信息时节奏更接近纸面阅读。
- 支持用音量键翻页，单手使用更从容。
- 动态内容以更平静的方式呈现，让屏幕保持舒适。

## 适合谁

Inkgram 适合使用墨水屏手机、阅读器或平板，并希望在 Telegram 中获得更简洁阅读体验的人。

如果你喜欢把注意力留给消息本身，而不是界面的动效与色彩，Inkgram 正是为这种使用方式准备的。

Inkgram 是基于 Telegram X 的非官方定制项目，与 Telegram 官方没有隶属关系，也不代表 Telegram 官方立场。
